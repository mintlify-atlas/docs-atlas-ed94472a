## Your first command

After installing Corona CLI, run your first command to see worldwide COVID-19 statistics:

```bash
corona
```

This displays a comprehensive table with COVID-19 data for all countries, including cases, deaths, recoveries, and more.

## Basic usage

<Steps>

<Step title="View global data">
  Display COVID-19 statistics for all countries:

  ```bash
  corona
  ```

  For single-color output (better for some terminals):

  ```bash
  corona --xcolor
  # or shorthand
  corona -x
  ```
</Step>

<Step title="Check a specific country">
  Get data for any country by name:

  ```bash
  corona usa
  ```

  ```bash
  corona china
  ```

  ```bash
  corona italy
  ```

  Country names are case-insensitive and flexible.
</Step>

<Step title="View US states data">
  Display COVID-19 statistics for all US states:

  ```bash
  corona states
  ```

  Sort states by active cases:

  ```bash
  corona states --sort active
  # or shorthand
  corona states -s active
  ```
</Step>

</Steps>

## Sorting and filtering

### Sort by different metrics

Corona CLI supports sorting by multiple criteria:

```bash
# Sort by total cases
corona --sort cases
corona -s cases

# Sort by deaths
corona --sort deaths
corona -s deaths

# Sort by recoveries
corona --sort recovered
corona -s recovered

# Sort by active cases
corona --sort active
corona -s active
```

### Available sort options

- `country` - Sort alphabetically by country name
- `cases` - Total confirmed cases
- `cases-today` - New cases reported today
- `deaths` - Total deaths
- `deaths-today` - New deaths reported today
- `recovered` - Total recovered patients
- `active` - Currently active cases
- `critical` - Critical condition patients
- `per-million` - Cases per million population

### Reverse sort order

Reverse the sort order with the `--reverse` flag:

```bash
corona --sort active --reverse
corona -s active -r
```

### Limit results

Display only a specific number of entries:

```bash
# Show top 10 countries
corona --limit 10
corona -l 10

# Show top 5 countries by deaths
corona --sort deaths --limit 5
corona -s deaths -l 5
```

## Visualizations

### Bar charts

Display data as bar charts for the top countries:

```bash
# Bar chart for top 10 countries
corona --bar
corona -b

# Bar chart for top 5 countries by deaths
corona --bar --sort deaths --limit 5
corona -b -s deaths -l 5

# Bar chart by recovered cases
corona --bar --sort recovered
corona -b -s recovered
```

### Line charts

Visualize COVID-19 trends over time for specific countries:

```bash
# Line chart for USA
corona usa --chart
corona usa -c

# Logarithmic line chart for China
corona china --chart --log
corona china -c -g
```

<Tip>
Logarithmic charts (`--log` or `-g`) are useful for visualizing exponential growth patterns in pandemic data.
</Tip>

## Output options

### Minimal output

For a clean, bare-bones table without additional information:

```bash
corona --minimal
corona -m
```

### JSON output

Get raw JSON data for programmatic use:

```bash
corona --json
corona -j

# JSON for specific country
corona usa --json
```

<Note>
JSON output is perfect for integrating Corona CLI into scripts, dashboards, or other applications.
</Note>

## Combining options

You can combine multiple flags for powerful queries:

```bash
# China data with single color and sorted by cases
corona china -x -s cases

# Top 5 countries by deaths with bar chart
corona -b -s deaths -l 5

# US states sorted by cases today, limited to 10
corona states -s cases-today -l 10

# Minimal output for top 15 countries
corona -m -l 15
```

## Getting help

View all available commands and options:

```bash
corona help
corona --help
```

## Example workflow

Here's a typical workflow for tracking COVID-19 data:

<Steps>

<Step title="Check global overview">
  ```bash
  corona -l 10
  ```
  View the top 10 countries by total cases.
</Step>

<Step title="Investigate specific country">
  ```bash
  corona usa --chart
  ```
  See detailed data and trend chart for the USA.
</Step>

<Step title="Compare US states">
  ```bash
  corona states -s cases-today -l 5
  ```
  Find which states have the most new cases today.
</Step>

<Step title="Export data">
  ```bash
  corona usa --json > usa-data.json
  ```
  Save JSON data for further analysis.
</Step>

</Steps>

<Tip>
Corona CLI updates automatically check for new versions. Keep your installation up to date for the latest features and data sources.
</Tip>
