## Track COVID-19 from your terminal

Corona CLI is a command-line tool that delivers real-time Coronavirus disease (COVID-19) statistics directly to your terminal. Built with Node.js, it provides instant access to global pandemic data with powerful filtering, sorting, and visualization capabilities.

## Available data points

Corona CLI provides comprehensive COVID-19 statistics including:

- **Country** - Location name
- **Cases** - Total confirmed cases
- **Deaths** - Total deaths
- **Recovered** - Total recovered patients
- **Active** - Currently active cases
- **Critical** - Critical condition patients
- **Per Million** - Cases per million population
- **Cases Today** - New cases reported today
- **Deaths Today** - New deaths reported today

## Trusted data sources

Corona CLI uses the NovelCOVID API, which aggregates data from reputable sources including:

- World Health Organization (WHO)
- U.S. Centers for Disease Control and Prevention (CDC)
- National Health Commission (NHC) of China
- WorldMeter
- Government health departments worldwide

<Tip>
Corona CLI requires Node.js version 12 or higher. Check your Node.js version with `node --version`.
</Tip>
