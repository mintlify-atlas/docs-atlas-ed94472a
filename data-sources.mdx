## Primary data source

Corona CLI uses the [NovelCOVID API](https://disease.sh/), which aggregates data from multiple authoritative sources to provide real-time COVID-19 statistics.

<Info>
  The NovelCOVID API is built on top of [WorldMeter](https://www.worldometers.info/coronavirus/) data, which provides frequently updated global statistics.
</Info>

## Data aggregation

<Note>
  Corona CLI serves over 12+ billion queries by aggregating data from these authoritative sources through the NovelCOVID API, providing real-time access to:
  - Country-level statistics
  - US state-level data
  - Global totals
  - Historical trends
</Note>

## Data metrics

The CLI provides the following data points:

- **Cases**: Total confirmed cases
- **Cases today**: New cases reported today
- **Deaths**: Total deaths
- **Deaths today**: New deaths reported today
- **Recovered**: Total recovered cases
- **Active**: Currently active cases
- **Critical**: Cases in critical condition
- **Per million**: Cases per million population

## Data freshness

<Warning>
  Data is updated regularly from source organizations. The frequency of updates depends on each country's reporting schedule. Most data is updated at least once daily.
</Warning>

## Data accuracy

While Corona CLI strives to provide accurate information by sourcing from authoritative organizations, please note:

- Data accuracy depends on reporting from individual countries and health organizations
- There may be delays in reporting from some regions
- Historical data may be revised as countries update their numbers
- For critical health decisions, always consult official health authorities
