The states command provides detailed COVID-19 statistics for all US states and territories. This is particularly useful for monitoring the pandemic situation across different regions of the United States.

## Basic usage

```bash
corona states
```

This displays a comprehensive table with COVID-19 data for all US states, including:

- State name
- Total cases
- Cases reported today
- Total deaths
- Deaths reported today
- Active cases
- Cases per million population

## Display options

The states command supports all global display options:

<CodeGroup>




## Sorting states data

<ParamField path="sort" type="string" default="cases">

</ParamField>

You can sort the states data by any field to identify the most affected regions:

<CodeGroup>

```bash By active cases
corona states --sort active

```

```bash By cases per million
corona states --sort per-million
corona states -s per-million
```

```bash Alphabetically
corona states --sort state
```
</CodeGroup>

## Filtering results

### Limit entries

Display only the top N states:

```bash
# Top 10 affected states
corona states --limit 10
corona states -l 10

# Top 5 by deaths
corona states --sort deaths --limit 5
corona states -s deaths -l 5

# Top 20 by active cases
corona states --sort active --limit 20
corona states -s active -l 20
```

### Reverse order

View states with the lowest values:

```bash
# States with fewest cases
corona states --sort cases --reverse
corona states -s cases -r

# Bottom 10 by active cases
corona states --sort active --reverse --limit 10
corona states -s active -r -l 10
```

## Understanding the output

The states table includes:

- **State**: Full state name or territory
- **Cases**: Total confirmed COVID-19 cases since tracking began
- **Cases (Today)**: New cases reported in the last 24 hours
- **Deaths**: Total deaths attributed to COVID-19
- **Deaths (Today)**: New deaths reported in the last 24 hours
- **Active**: Currently active cases in the state
- **Per Million**: Cases per million residents (population-normalized)

<Note>
The states data includes all 50 US states plus territories like Puerto Rico, Guam, US Virgin Islands, and others.
</Note>

## Data sources

States data is aggregated from:
- State health departments
- CDC (Centers for Disease Control and Prevention)
- Local health authorities
- COVID Tracking Project

<Note>
Data is updated regularly throughout the day. The last update timestamp is displayed at the bottom of the output.
</Note>

## Frequently compared metrics

### Total cases vs cases per million

**Total cases** shows absolute numbers:
```bash
corona states --sort cases
```

**Cases per million** normalizes by population:
```bash
corona states --sort per-million
```

Use per-million for fair comparisons between states with different populations.

### Active cases vs total cases

**Total cases** includes all historical cases:
```bash
corona states --sort cases
```

**Active cases** shows current burden:
```bash
corona states --sort active
```

Active cases better represent current healthcare system load.

### Cases today vs total cases

**Cases today** shows current trends:
```bash
corona states --sort cases-today
```

**Total cases** shows cumulative impact:
```bash
corona states --sort cases
```

Use "cases today" to identify emerging hotspots.
